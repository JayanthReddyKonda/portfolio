## 🏛️ Platform At A Glance

- **Core Framework**: Next.js (App Router, Turbopack)
- **UI & Runtime**: React 19, Framer Motion
- **3D & Creative Shaders**: Three.js, React Three Fiber, Custom WebGL Canvas Shaders
- **Styling Architecture**: Tailwind CSS v4, Modern CSS View Transitions
- **Design Paradigm**: *Emerald Sophistication* (Deep velvet forest green, sage slate, luminous moss accent, warm alabaster typography)
- **Deployment & Build Model**: Fully static prerendering (SSG), 100% offline-resilient local asset pipelines, sub-50ms TTFB.
